# deepark 分层记忆

LivingMemory 的普通长期记忆继续按会话隔离。新增公开资料库只保存本人明确授权的字段，在同一 QQ 的已授权私聊和群聊中自动注入。不根据昵称认人，不把别人的资料当成你的，也不自动公开过去聊天。

当前开放：群 107861837 与管理员 1431209261 的私聊。群友可在该群维护自己的公开资料；他们的私聊仍需管理员另行授权，添加公开资料不会放开私聊白名单。

## 使用

由本人直接发送（不要引用或转发）：

```
/deepark 公开记住 昵称=小雨
/deepark 公开记住 喜欢的干员=阿米娅
/deepark 公开记住 游戏偏好=喜欢看剧情和皮肤，不太卷强度
/deepark 公开记住 剧透偏好=不要剧透新主线
/deepark 公开记忆
/deepark 取消公开 喜欢的干员
/deepark 取消公开 全部
```

公开内容应是你愿意在群里提及的自述，每个字段最多80字。相同字段再次保存即替换。不能指定别人 QQ 修改或查询别人的资料。未使用公开指令的普通聊天仍交给 LivingMemory，保持原隔离规则。

撤回只停止公开资料层未来注入，并阻止仍在生成的旧版本回复。已经发送到群里、存在普通会话上下文或 LivingMemory 中的内容不因该命令自动删除；服务器备份也不会被改写。需要删除原会话记忆时另用 LivingMemory 管理功能（其 forget 为软归档）。

## 实现与运行

- companion v0.5.0；public_profile.py 管 SQLite，main.py 校验 SDK 身份和会话权限。
- 主键：平台实例 + 机器人 QQ + 实际发送者 QQ，仅注入当前发言者资料。
- 数据：`data/plugin_data/deepark_companion/public_profiles.db`，记录来源会话、授权时间和版本。
- 仅 `public_profile_sessions` 与原生白名单交集启用，遵守会话/插件开关；非管理员也只能操作本人。
- 不使用模型判定授权，不向模型提供共享写入工具，不查询或迁移 LivingMemory 的历史私聊。
- 本地 SQLite 无模型依赖，不增加 embedding/LLM 请求，最多注入四条短资料。
- 回滚：执行本次 `/home/grainrain/astrbot-backups/public-profile-*/rollback.sh` 对应具体备份；恢复插件和配置，保留新资料数据库但旧版不读取。不要回滚整库覆盖期间的新聊天。

# deepark 运维与验收

## 当前状态

人设、图片理解（GLM-4.6V）、语音识别（GLM-ASR-2512）已配置。插件已加载，官网资讯每6小时刷新、24小时失效。插件群白名单为空，主动发言关闭；需用户给出目标群后激活，不能将现有私聊白名单误当群白名单。

本地28项测试、AstrBot容器17项集成测试通过。合成图片/音频已通过真实模型适配器调用；没有向QQ群发送测试。真实QQ媒体下载链路尚未验收。

## 激活后命令

- `/deepark 记忆`：查看当前群自己的长期记忆。
- `/deepark 记住 名称=内容`：保存；相同名称覆盖旧值。
- `/deepark 忘记 名称` 或 `/deepark 忘记 全部`：删除插件记忆及本人近期缓存、机器人缓存，并阻止延迟写回。不会删除AstrBot原生数据库、QQ记录或历史备份。其他成员转述不在自动删除范围。
- 管理员 `/deepark 群记住 名称=内容`、`/deepark 群忘记 名称`：维护本群背景。
- 管理员 `/deepark 安静`、`/deepark 活跃`：暂停/恢复主动发言资格，@聊天仍可使用。

删除全部后自动记忆保持关闭，显式“记住”仍可使用。当前没有恢复自动记忆的命令。不要把临时调侃记作稳定偏好。

## 默认节奏

次数、起止小时和间隔可在插件WebUI配置中修改；次数0表示关闭该类主动行为。无效输入回退默认值，数值受范围限制。

北京时间09–23点；机器人发言后至少3分钟安静，主动尝试至少间隔10分钟。插话每日最多8次；冷场开题每日最多2次、间隔4小时，群静默至少1小时且最近24小时有人说话；上次主动发言后无人回应不再开题。失败或放弃也占用预算，防止重试刷屏。启动后冷场调度预热30分钟。

# 恢复多模态部署前的完整cmd_config.json；会覆盖此后主配置变动

以上脚本按一次性恢复设计，已执行过时应先检查目录状态，不要反复运行。不要为回退配置直接覆盖整套聊天数据库。最初全量备份含登录态和密钥，始终留在服务器受限目录。

## 限制与剩余验收

- 目标群未指定，群功能尚未激活；激活时必须关闭重复原生概率触发与原生历史注入，并复查权限。
- 官网缓存只包含公告标题，不能据此声称读过全文；网络新梗的来源检索尚未完成。
- 内容过滤是规则检查与人格约束，不保证全面语义审核；当前原生关键词规则为空。
- Paratera `/models`返回88个模型，音频相关仅GLM-ASR-2512，未找到可确认TTS模型。语音输出关闭。
- 人格对比样本很小，9次调用共6594 tokens；独立视觉探针102、ASR成功探针127 tokens。适配器复测及失败请求未取得完整计费统计，不能将这些数相加称为总费用。
